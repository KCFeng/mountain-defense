貓咪山脈防禦戰 (Cat Mountain Defense)

這是一個基於 HTML5 Canvas 與 Vanilla JavaScript (搭配 Tailwind CSS) 開發的網頁版輕量級塔防同人遊戲。玩家需要在貓咪山脈的防線中，透過召喚與合成英雄，抵禦不斷繞圈的怪物大軍。

🎮 遊戲特色

環形路徑設計：怪物會沿著部署區外圍不斷繞圈，考驗玩家的佈陣策略。

同星級合成機制：網格內集滿 3 隻同階級角色即可合成，有機會跨階級晉升！

響應式介面 (RWD)：支援電腦與手機端操作，擁有防誤觸與懸浮資訊面板設計。自動動態縮放引擎確保在任何視窗大小下難度一致。

獨立難度曲線：提供簡單、中等、困難三種模式，且怪物血量會隨波數獨立成長。

實體圖形渲染：支援透明 PNG Sprites 渲染，角色會依數量以前後堆疊方式顯示，並支援怪物專屬圖片載入。

📜 遊戲規則

1. 核心目標

勝利條件：成功撐過第 25 波的戰鬥時間，且場上存活怪物數量 <= 50 隻。

失敗條件：任何時刻，若防線被突破（場上存活怪物 > 50 隻），任務即刻失敗。

警報機制：當場上怪物達到 40 隻時，畫面會出現紅色閃爍警報。

2. 角色階級與能力

場上最多允許 23 隻角色，花費 50 金幣可隨機召喚。同一網格內僅能存在同一個「角色名稱」的單位，且有堆疊上限：

⚪ 一般 (白)：傷害 10 / 射程 100 / 攻速 1.2s (最高堆疊 3 隻，可售出 +5G)

🔵 稀有 (藍)：傷害 25 / 射程 110 / 攻速 1.0s (最高堆疊 3 隻，可售出 +10G)

🔴 英雄 (紅)：傷害 70 / 射程 120 / 攻速 0.8s (最高堆疊 3 隻，可售出 +25G)

🟣 傳說 (紫)：傷害 250 / 射程 130 / 攻速 0.6s (最高堆疊 1 隻，不可售出)

🟡 神話 (金)：傷害 500 / 射程 150 / 攻速 0.4s (最高堆疊 1 隻，不可售出)

MP 回復與技能：戰鬥與冷卻階段期間，角色每秒回復 1 點 MP。MP 滿時，有機率發動特殊技能 (例如：法師光箭、騎士衝擊之暈)。

3. 波次與難度

總共 25 波。每波戰鬥持續 30 秒，隨後有 5 秒冷卻時間。每逢 5 的倍數波次（5, 10, 15, 20, 25）為 Boss 關卡。

簡單 (EASY)：一般波次 30 隻 / 王關 1 隻 (怪物血量 x1.0, 跑速 x1.0)

中等 (NORMAL)：一般波次 40 隻 / 王關 2 隻 (怪物血量 x2.0, 跑速 x1.5)

困難 (HARD)：一般波次 50 隻 / 王關 3 隻 (怪物血量 x4.0, 跑速 x2.0)

備註：各關卡的怪物從怪物能力表隨機生成，每一波同類關卡的怪物血量皆會較上一波穩定成長 10%。

🛠️ 技術棧

HTML5 Canvas (2D 渲染)

JavaScript (ES6+ 遊戲邏輯與物件導向)

Tailwind CSS (UI 佈局與響應式設計)

🚀 如何運行

本專案為純前端應用，無須安裝任何後端環境或套件：

將專案 Clone 到本地端。

確保角色與怪物的 .png 圖片資源已放在與 HTML 檔案相同的資料夾內。

直接點擊兩下開啟 index.html 即可在瀏覽器中遊玩。

你也可以直接開啟下列網址直接在線上遊玩：https://kcfeng.github.io/mountain-defense/
